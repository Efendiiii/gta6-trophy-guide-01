An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PS5 — a checklist saved in the browser, a roadmap to the platinum, a missables page, and an original guide for every trophy with its sources cited.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed.
